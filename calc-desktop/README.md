# Windows 関数電卓

Tkinter製のWindows 10/11 64-bit向けGUI関数電卓です。GitHub ActionsのWindowsランナーでPyInstallerを使って単体EXEをビルドします。利用者側でPythonのインストールは不要です。

## 機能

- 四則演算、括弧、べき乗
- sin / cos / tan（DEG / RAD切替）
- 平方根、立方根、4乗根
- 常用対数 log、自然対数 ln
- π、e、クリア、バックスペース、キーボード入力

## ダウンロード

GitHub Actionsの `Build Windows calculator EXE` ワークフローを開き、成功した実行の Artifacts から `calc-chatgpt-20261014-windows-x64` をダウンロードしてZIPを展開してください。EXEは `calc-chatgpt-20261014.exe` です。
