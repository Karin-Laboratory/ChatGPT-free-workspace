# 運用Runbookと再現チェック

## 0. 実行前ゲート

- [ ] 自分のnote URLと関心テーマが入力されている
- [ ] 今回の新規フォロー上限と許可が明記されている
- [ ] note本人アカウントでログイン状態を確認できた
- [ ] AIブラウザーが**サイト内でクリック可能**だと確かめた
- [ ] サイトの規約、警告、停止要求に従う
- [ ] 過去の対象一覧があれば重複除外に使用できる

どれか不明なら、その要素に依存する操作は行わない。候補選定だけ行うことはできる。

## 1. 候補発見

1. 自分の記事・プロフィールで主題と想定読者を確認。
2. noteの検索・関連記事・公開クリエイターページから候補を発見。無差別な巡回、個人情報収集をしない。
3. 候補のプロフィール、公開されている最近の記事を実際に読む。
4. 「自分が読みたいか」「共通テーマが具体的にあるか」で選ぶ。フォローバックの可能性は選考軸にしない。
5. 憶測で記事や人物を作らず、確認URLを記録する。

## 2. 既フォロー確認と実操作

1. 候補のプロフィールを開き、**その画面が本人のnoteログイン状態**であることを確認。
2. 既に「フォロー中」なら操作せず `ALREADY_FOLLOWING`。
3. 「フォロー」相当が表示され、今回の許可・上限内であれば、**一度だけ**クリック。
4. ページ状態が「フォロー中」等に変化したことを再確認。
5. 確認できたときだけ `FOLLOWED_CONFIRMED`。変化が確認できないときは `UNKNOWN`、再クリックせず停止または保留。
6. 次の候補に進む前に今回の新規フォロー件数と上限を確認。

ボタンの文言・配置・画面遷移は変わり得る。固定座標や盲目的な連打で実行しない。

## 3. 停止条件（最優先）

- 利用制限・警告・CAPTCHA・アクセス拒否・安全柵と思われる画面
- フォロー表示の不一致、対象の取り違え、本人ログインの喪失
- サイトの反応が不明なままの再試行要求
- 予定した件数の達成、ユーザーの停止依頼
- ログインやブラウザー操作権限がない状態

停止後は制限回避や別アカウント・別経路での継続をしない。

## 4. 作業記録の例

```json
{
  "date": "YYYY-MM-DD",
  "environment": "ChatGPT Work / other verified interactive browser",
  "theme": "自分の関心テーマ",
  "requested_candidates": 5,
  "authorized_new_follows": 3,
  "candidate_count": 5,
  "followed_confirmed": 2,
  "already_following": 1,
  "review_only": 1,
  "unknown": 1,
  "stopped": true,
  "stop_reason": "1件の状態を確認できなかった",
  "candidates": [
    {
      "display_name": "公開表示名",
      "profile_url": "https://note.com/example",
      "article_url": "https://note.com/example/n/example",
      "shared_interest": "確認できた共通の関心",
      "result": "FOLLOWED_CONFIRMED"
    }
  ]
}
```

**これは架空の書式例**であり、実行結果ではない。公開時は個人の行動履歴を必要以上に公開しない。認証情報、Cookie、セッションID、非公開の通知やDMの内容は記録しない。

## 5. 事後検証

- 成功数は「操作後のフォロー状態を確認できた数」のみ。
- フォロワー増加と新規フォロー数を混同しない。相手がフォローバックしたかは別の事象。
- 記事PVやスキの変化を単純にこの活動の因果効果と見なさない。
- 操作を再開するときは重複を調べ、**前回の中断理由を解消した場合のみ**検討。

## 6. 実行できないとき

- 読み取り専用ブラウザー: 候補URLと理由だけ報告
- 認証なし: 手動ログインを依頼し、フォロー済みとは報告しない
- 画面変更: 記録済み手順を盲信せず、現在の画面で1件ごとに検証
- 失敗・安全制限: 停止し、エラーと確認済み件数をそのまま報告

## このRunbookの再現性の意味

**再現対象は「人間の関心に沿って候補を選び、許可された少人数を確実に確認しながらフォローする判断手順」**です。異なるアカウントに同じ候補が表示されることや、同じ人がフォローバックすること、UIの不変性を保証するものではありません。
