# AIフォロー後のメッセージ交流手順

更新: 2026-11-02

## 目的と原則

AIが本人の興味に合うnoteクリエイターを見つけてフォローし、**本人へフォロー結果を通知する**既存フローの次段階として、自然な交流のためのDM文案を用意する。フォローはDM送信の許可ではない。**フォロー時にDMを自動送信しない**。文面は本人が確認し、送信は別途、明示的な指示がある場合に限る。

## 基本メッセージ（下書き・対人一人称「私」）

はじめまして。突然のメッセージ失礼します。

このたびフォローさせていただきました。

実は、私の興味や好みをAIに分析してもらい、気が合いそうなクリエイターさんをAIが探して、自動でフォローするという実験をしています。フォローした方は、あとからAIが私に教えてくれる仕組みです。

そんなご縁でこちらにたどり着きました。😊

私もAIを使った個人開発や、日々の試行錯誤について記事を書いています。もしご興味があれば、気が向いたときに覗いていただけるとうれしいです。

これからどうぞよろしくお願いします！

## よりよい個別化

送信前に相手の公開記事を実際に読む。読んだ記事の題名や、印象に残った具体的な内容について、**事実に基づいた一文**を添えてよい。未読なのに「拝読しました」と書かない。相手と興味が一致する根拠が弱ければ送らない。相手の名前・作品内容を推測で補わない。

## 実行ゲート

1. 本人アカウントの認証済み環境で、相手の公開プロフィールと記事を確認する。
2. フォロー結果が確認できており、DMの受信許可が実際の画面から確認できる場合のみ候補にする。受信設定は変わるため、古い情報を前提にしない。
3. 送信内容を本人に提示し、**宛先と個別文面について本人の送信指示を得る**。フォローの承認をDM送信の承認に流用しない。
4. 現行のnote規約・利用上限・UIに従い、無差別送信、連続テンプレート送信、制限回避をしない。受信者が嫌がる・反応がない・警告が出た場合は追送せず停止する。
5. 送信後は成功表示を確認。未実行・未送信・失敗を区別して報告する。公開GitHubには送受信本文、相手の非公開情報、Cookie、トークンを保存しない。

## 記録項目（非公開運用ログ）

候補／相手の公開記事URL／実際に読んだ記事／個別化した理由／DM送信可否／本人承認／送信結果／送信日時。フォロー数やDM数を競わず、返信を要求しない。

## 非目標

AIフォローの直後に自動DMを配信する仕組み、フォローバック誘導、閲覧やスキの要求、受信設定を迂回する方法は対象外。
