# どっぴぃから Work を経由して Discord に連絡する

2026年11月25日 23:30 JST、Windows の接続済みPCで送信テストに成功。人が指示文をコピーして貼り付ける必要はなかった。

## 成功した手順

1. **どっぴぃの会話で**、Discord の送信先・用件を指定し、接続済みの Windows PC の Work に引き継ぐよう頼む。
2. **どっぴぃが**、対象PCを指定して Work に短い指示を渡す。送信先、送る文面、重複していれば送らないこと、送信後に画面で確認することを明記する。
3. **Work が**、対象PCでサインイン済みの Chrome を、ChatGPT のブラウザ操作機能で開く。指定チャンネルの表示を確認し、承認された文面だけを送る。
4. **Work が**、投稿後に本文と時刻が画面に出たことを確認し、どっぴぃに返す。どっぴぃは「指示を渡した」と「Discord に投稿できた」を区別して報告する。

## 今回確認したこと・していないこと

- 成功したのは、既存チャンネルへの接続テスト1件。実機試験の依頼は重複送信していない。送信確認と相手の受領・返信は別。
- PCが接続済みでも、どっぴぃの会話からブラウザを直接操作できない場合がある。今回は **PCを指定した Work** が操作できた。PCの切断中やサインアウト中、無人での常時送受信まで確認したわけではない。
- チャンネルが見えない、操作できない、再ログインが必要、送ったか判別できない場合は、むやみに再送しない。どの段階で止まったかを報告する。実測や作業履歴は元の GitHub の記録に残す。
- 公開リポジトリには、非公開チャンネルへのリンク・識別子、アカウント情報、認証情報、やりとりの転載を載せない。
